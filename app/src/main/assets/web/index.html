API Documentation

The Radio app provides a REST API to control playback and query information.

API Reference

GET /api/status

Returns current playback status.

Response Example:
{
  "isPlaying": true,
  "currentStationUuid": "fc080549-...",
  "metadata": "Artist - Title"
}

GET /api/stations

Returns all stations in collection.

Response Example:
[
  {
    "uuid": "fc080549-...",
    "name": "Station Name",
    "hasImage": true
  }
]

GET /api/image/{uuid}

Returns the image for a specific station.

Response: Image (binary data, JPEG)

GET /api/config

Returns the app version.

Response Example:
{ "version": "15.1" }

POST /api/play/{uuid}

Starts playback of a specific station.

Response Example:
{ "status": "ok" }

POST /api/pause

Pauses current playback.

Response Example:
{ "status": "ok" }

POST /api/resume

Resumes current playback.

Response Example:
{ "status": "ok" }

POST /api/next

Plays the next station.

Response Example:
{ "status": "ok" }

POST /api/prev

Plays the previous station.

Response Example:
{ "status": "ok" }
